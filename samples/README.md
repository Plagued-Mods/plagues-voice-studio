## Production checklist

1. Use genuine recordings generated by the desktop application. The three sample WAVs listed above have now been supplied.
2. Preserve the original file and record the precise engine/model and software version. Speaker permissions and hardware metadata have not been independently verified.
3. Keep the unmodified WAV; the web MP3 derivatives were encoded from the user-supplied recordings with FFmpeg.
4. For later repository publication, upload original WAV and web MP3 files to `samples/audio/` and record permissions for each voice. Never include private reference clips.
5. The updated Plagued Mods website package already contains MP3s, a configured `samples.json` manifest, and working audio-player paths.
6. Preview the website through an HTTP server before deployment, and confirm browser playback and voice rights. Do not publish unresolved media links.

The website showcase is designed to hide audio-player controls until its audio manifest includes real published files. The live text-to-speech website demo is a separate future milestone documented in [ROADMAP.md](../ROADMAP.md).
